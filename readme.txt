Modular opinion form with star rating, shortcode support, built-in spam protection, and JSON-LD schema markup.

== Description ==
Opiner Me is a lightweight plugin for collecting user opinions with star ratings.  
Includes SEO-friendly JSON-LD markup and basic spam protection.  
Easily add opinion forms anywhere with a simple shortcode.

== Installation ==
1. Upload the plugin files to /wp-content/plugins/opiner-me/ or install via the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Place the [opiner_me] shortcode in any post or page to display the opinion form.

== Features ==
* Opinion form with star rating
* Shortcode integration
* SpamGuard module for basic filtering
* Logger and LogViewer for debugging
* SEO-friendly JSON-LD structured data

== Frequently Asked Questions ==
= How do I add an opinion form? =
Place the [opiner_me] shortcode in any post or page.

= Can I change the look of the stars? =
Yes. You can style the stars with CSS. The plugin uses standard HTML markup.

= Where can I see submitted opinions? =
All opinions are listed in the admin panel under 'Settings > Opiner Me'.

= Does the plugin block spam? =
Yes. Basic spam filtering is included via the SpamGuard module.
